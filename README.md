# Rev. Dr. KEHINDE OJOARO - Professional Portfolio Website

A clean, responsive, and modern portfolio website designed and developed for **Rev. Dr. KEHINDE OJOARO**, a Software & Web Developer holding a B.Sc. in Computer Science. 

This website showcases his academic background, technical skills, featured web/software engineering projects, and direct contact options using a customized **Green, Gold-Yellow, and White** color theme.

---

## 🌟 Key Features

- **Responsive Single-Page Layout**: Smooth scroll navigation across all major sections: **Home**, **About**, **Skills**, **Work**, and **Contact**.
- **Custom Color Palette**: Deep Forest Green (`#046A38`), Warm Gold/Yellow (`#FFC72C`), and Pure White (`#FFFFFF`).
- **Profile Image Integration**: Properly rotated, framed, and styled avatar badge showcasing credentials.
- **Interactive Project Showcase**: Dynamic category filter (All, Web Apps, Software Systems, Academic Platforms) and modal popups for detailed project information.
- **Animated Skill Progress Indicators**: Visual skill bars representing competencies in Frontend, Backend, and Core Computer Science.
- **Interactive Contact Form & Toast Alert**: Responsive contact submission form with simulated real-time visual feedback via toast notifications.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure.
- **CSS3**: Custom CSS variables, CSS Flexbox/Grid layouts, custom keyframe animations, and image transform orientations.
- **FontAwesome 6**: Modern iconography.
- **Google Fonts**: Modern typography featuring *Poppins*.
